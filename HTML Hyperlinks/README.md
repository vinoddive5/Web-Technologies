# HTML Hyperlinks Project

## 📌 About the Project

A simple HTML and CSS project demonstrating hyperlinks to external websites like Google, Microsoft Bing, and W3Schools.

## ✨ Features

- Simple and clean webpage design
- Hyperlinks to external websites
- Center-aligned content
- Basic HTML structure
- CSS styling

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🌐 Websites Included

- [Google](https://www.google.com/)
- [Microsoft Bing](https://www2.bing.com/)
- [W3Schools](https://www.w3schools.com/)

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `Contain_Hyperlink.html` in your web browser.
4. Click on any hyperlink to visit the website.

## 🎯 Learning Objectives

- Understand HTML structure.
- Learn to create hyperlinks using the `<a>` tag.
- Practice basic CSS styling.
- Understand webpage navigation.
