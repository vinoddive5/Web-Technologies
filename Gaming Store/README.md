# 🎮 Elite Gamer's Hub – Gaming Store Website

## 📌 Project Overview
Elite Gamer's Hub is a gaming store website created using HTML5 and CSS3. It displays game images, names, ratings, prices, platforms, storage requirements, and game modes in an attractive card layout.

## ✨ Features
- 🎮 Attractive gaming website header
- 🖼️ Game cards with images
- ⭐ Game names, genres, and star ratings
- 💻 Platform and storage information
- 💰 Game prices
- 🛒 Buy Now buttons
- 🎨 CSS styling with colors, borders, and rounded corners
- 📦 Flexbox layout
- 🦶 Footer with copyright information

## 🕹️ Games Included
- Grand Theft Auto VI (GTA VI)
- EA Sports FC 26
- Red Dead Redemption 2 (RDR 2)
- Candy Crush

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. View the game cards and their details.

## 🎯 Project Objective
To practice HTML elements, image attributes, CSS styling, and Flexbox by building a simple gaming store website.
