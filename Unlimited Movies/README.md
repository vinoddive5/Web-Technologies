# 🎬 Lumora Studios – Movie Streaming Website

## 📌 Project Overview
A movie website built using HTML5 and CSS3, featuring movie posters, descriptions, ratings, and trending movies with a dark-themed design.

## ✨ Features
- 🎬 Movie posters and descriptions
- ⭐ Star ratings
- 🔥 Trending movies section
- 🧭 Navigation bar
- 🎨 Dark-themed interface
- 🦶 Footer with copyright information

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox

## 🚀 How to Run
1. Download or clone the repository.
2. Open `index.html` in your browser.
