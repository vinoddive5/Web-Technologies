# 🛍️ Bravix Digital Hub – Gadget Showcase Website

## 📌 Project Overview
A gadget showcase website built using HTML5 and CSS3, featuring laptops, smartphones, and smartwatches with product images, descriptions, prices, and a promotional sale banner.

## ✨ Features
- 💻 Laptop, smartphone, and smartwatch products
- 🖼️ Product images and descriptions
- 💰 Product prices in Indian Rupees
- 🔥 Mega Electronics Sale promotional banner
- 🎨 Attractive layout with card shadows
- 🦶 Footer with copyright information

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox

## 🚀 How to Run
1. Download or clone the repository.
2. Keep all product images in the same folder as `index.html`.
3. Open `index.html` in your browser.
