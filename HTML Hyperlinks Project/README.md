# ✈️ Explore Incredible India

## About the Project
Explore Incredible India is a simple multi-page website developed using HTML and CSS. This project demonstrates the use of the **HTML Anchor Tag (`<a>`)** to navigate between webpages and create clickable image links.

Users can click on tourist place images to explore information about each destination.

## Features
- Navigate between multiple webpages using hyperlinks.
- Clickable images using the anchor tag.
- Display information about tourist destinations.
- Home, Next and Previous page navigation.
- Simple and attractive CSS design.

## Tourist Places
1. Taj Mahal – Agra, Uttar Pradesh.
2. Gateway of India – Mumbai, Maharashtra.
3. Hawa Mahal – Jaipur, Rajasthan.

## Technologies Used
- HTML5
- CSS3

## HTML Concepts Used
- Anchor Tag (`<a>`)
- Image Tag (`<img>`)
- Hyperlinks
- Image Hyperlinks
- Multi-page Navigation

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Run `index.html` in your browser.
4. Click on any image to navigate to its information page.
