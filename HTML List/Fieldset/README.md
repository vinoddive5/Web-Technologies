# HTML Fieldset Examples

This folder contains two HTML webpages created using HTML5 and CSS3. These examples demonstrate how to organize information using the `<fieldset>` and `<legend>` tags along with ordered and unordered lists.

## 1. FFieldsetExample.html – Colors and Sports

This webpage displays two separate sections using the `<fieldset>` and `<legend>` tags.

- **List of Colors:** Displays colors using an unordered list (`<ul>`).
- **List of Sports:** Displays sports using an ordered list (`<ol>`).

## 2. FieldsetExample.html – Student Hobbies and Subjects

This webpage displays student hobbies and subjects in two separate fieldsets.

- **List of Hobbies:** Displays hobbies using an unordered list with square bullets.
- **List of Subjects:** Displays subjects using an ordered list with lowercase alphabetical numbering.

## Technologies Used

- HTML5
- CSS3

**Purpose:** To practice HTML fieldsets, legends, ordered lists, unordered lists, and CSS styling.
