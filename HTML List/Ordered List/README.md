# HTML Ordered Lists

## Project Overview
A simple HTML and CSS project demonstrating Ordered Lists.

## Daily Routine
**File:** `DailyRoutine.html`

A webpage displaying daily activities in sequential order.

## Travel Booking
**File:** `TravelBooking.html`

A webpage displaying the steps involved in booking a trip.

## Technologies Used
- HTML5
- CSS3

## Concepts Covered
- Ordered List (`<ol>`)
- List Item (`<li>`)
- CSS Styling
- Margin and Padding

## Objective
To practise HTML Ordered Lists and basic CSS styling.
